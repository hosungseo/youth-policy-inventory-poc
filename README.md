# 청년정책 인벤토리 PoC

온통청년에 등록된 청년정책을 예산·성과·자격조건이 붙은 **범정부 청년정책 인벤토리**로 재구성하고,
자격 판정·신청은 **보조금24**에 연계하는 역할 분담을 공개 데이터로 시연하는 비공식 개념검증(PoC)입니다.

- 진단: 현재 온통청년 등록 데이터의 공백(신청 경로·지원규모·예산·성과·기본계획 매핑)
- 인벤토리: 정책별 통합 ID(온통청년 정책번호 · 보조금24 서비스ID · 기본계획 과제번호)와 필수 항목 충족도
- 중복·사각지대: 유사 사업 분포, 보조금24에만 있는 청년 서비스
- 설계안: 표준 항목, 갱신 책임, 단계별 추진안

## 데이터

- 온통청년 공개 정책검색 결과 (2026-09-23 수집)
- 공공데이터포털 「행정안전부_대한민국 공공서비스(혜택) 정보」 (serviceList · serviceDetail · supportConditions)

담당자 성명·연락처 등 개인 관련 항목은 싣지 않았습니다. 매칭 결과는 자동 추정치이며 행정기관의 공식 입장이 아닙니다.
